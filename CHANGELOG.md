# Release notes

## v1.0 — First public release

- Adventure of Chalvo, Score Attack!! and Pocket and Cushion editing.
- Native support for both verified ROM revisions, identified with SHA-1.
- Projects, undo/redo, graphics/audio dumps, and 2,048 KB patched ROM exports.
- Boss Rush, stage-number HUD, Proto 2 SRAM and debug-restoration enhancements.
- Proto 2 preferred at startup; dark mode by default.

All earlier numbered builds were local development builds. This is the first
public release, **v1.0**. Project schema 18 is an independent internal format.

Hardware testing remains pending. See README for compatibility and limitations.
